Telegram Bot Commands & Setup

Commands available directly in Telegram chat to manage projects and Kanban cards.

/plan <idea description>
Invokes Groq LLM to format raw text into a detailed technical plan and saves it locally as a markdown file.
/board
Displays the interactive Kanban board with inline Claim, Release, and Done action buttons.
/create-task <title>
Manually creates a new task or parses bulk bullet points into individual GitHub issues.
/push <draft_id>
Pushes a saved local draft plan directly to your GitHub repository as a new Issue.

Deployment & Environment Setup

Run LogicalFire locally or deploy to cloud hosting providers in minutes.

1. Local Setup with uv / Python

git clone https://github.com/LogicalFire/project-manager.git
cd project_manager_bot
uv sync
uv run python -m api.main

2. Docker Deployment

docker build -t logicalfire:latest .
docker run -d -p 8000:8000 \
  --env-file .env \
  logicalfire:latest
